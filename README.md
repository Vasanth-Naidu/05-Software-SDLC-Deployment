# Portfolio Module 05: Software Product SDLC, Self-Directed Innovation & Multi-Process Deployment (GE Capital)

## Executive Summary:
* **Domain:** Software Product SDLC, Self-Directed Innovation, Audit Automation, SQL Data Engineering & Enterprise Tool Adoption
* **Company Context:** GE Capital
* **Role:** Automation Engineer
* **Core Value Delivered:** Operative as a self-directed, floor-focused developer within GE Capital. While central IT focused on high-cap, long-horizon core systems, targeted the operational — medium and low-hanging fruit projects deemed too small or low-ROI for formal IT roadmaps. Scouted floor pain points via Gemba walks to build a personal pipeline of custom tools. Delivered immediate pain-point elimination, high user adoption, and strong appreciation across frontline operators, managers, and process heads/ owners.

---

## 1. Operational Challenge & Scope:

* **Central IT Roadmap Gaps & Ignored Floor Pain:** Core IT teams prioritized large-scale enterprise overhauls, leaving medium and low ROI operational bottlenecks unaddressed with zero prospect of formal tech resolution.
* **Relocation Audit Bottlenecks & Complex Contracts:** Cendant Mobility Services audited employee relocation expense bills (U-Haul, self-move, carrier receipts) across hundreds of corporate client contracts. Pricing tiers varied by corporate employee grades and perks. Manual cross-referencing against physical contract books constrained output to 2–4 audits per day for GE India auditors.
* **Non-Value-Added Reporting Overhead:** Senior SMEs and Team Leads spent hours manually executing SQL queries, cleansing data, formatting charts, and populating periodic reports or recurring reports for client & internal leadership reviews, pulling them away from core floor support and training.
* **SQL Knowledge Barrier Across Teams:** Operations managers and analysts lacked advanced SQL coding skills, creating severe person-dependency on technical SMEs whenever custom operational queries or data extracts were required.
* **Fragmented Enterprise Communications & Operational Updates:** Critical process updates, policy changes, and company announcements lacked a centralized, real-time channel. Employees returning from leave frequently missed updates, resulting in process errors.

---

## 2. SDLC Execution & eLab Innovation Framework:

1. **"Single-Run" Niche Scouting & Intake** — Solved operational bottlenecks overlooked by central IT by converting frontline pain points into agile, lightweight software builds without competing for formal IT roadmap budgets.
2. **Cendant Wizard | Audit Automation Build (Green Belt Project)** — Transformed from a junior auditor into a tool creator by self-digitizing complex contract pricing books into MS Excel VBA macros (reducing 6-point invoice validation time). Following a 5x productivity jump (10 audits/day), was pulled off production to architect the full-scale **Cendant Wizard** using Visual Basic 5 (VB5) and SQL DBs — clearing Cedants all-time audit backlogs and prompting an client site visit, to understand the unique approach taken and experience GE's culture of continuous improvement DNA.
3. **Solution Wizard | Automated Reporting (Green Belt Project)** — Developed an automated reporting engine connected directly to SQL databases to eliminate Non-Value-Added (NVA) work. The tool automatically executed pre-defined SQL queries, cleansed raw data, generated graphical infograms, and populated executive review decks without manual intervention.
4. **Anukara | Enterprise Communication Platform Build & Expansion** — Concepted, coded, deployed, and marketed **Anukara**—a persistent desktop title-bar ticker app that pushed real-time process updates and company announcements. Engineered search functionality ("Google-like" past update search) and admin controls, securing recognition as the **GE Capital's approved, 8th official communication tool** across GE Capital BPO India with **9,000+ active users**.
5. **SQL Genie | Drag-and-Drop Query Builder** — Engineered an ahead-of-its-time, visual SQL query engine. Allowed non-technical users to drag and drop database tables, select target fields, apply visual filters/conditions, and automatically build, run, cleanse, and export complex SQL queries to Excel with repository storage capabilities.
6. **Self-Directed Scouting & Best Practice Marketing** — Managed an open visual project tracker at the desk for manager reviews while independently scouting operational friction across teams, executing full-stack SDLC, and marketing finished features across departments.

---

## 3. Core Software Engineering & Product Toolkit Built:

* **Cendant Wizard (Green Belt Tool):** Visual Basic 5 (VB5) and SQL database application automating corporate relocation contract audits, tier validation, pricing verification, and error-flagging commentary.
* **Solution Wizard (Green Belt Tool):** Automated SQL data extraction and reporting tool that runs scheduled queries, cleanses data, and auto-populates executive infogram decks.
* **Anukara Desktop Ticker Engine:** GE Capital's approved, 8th official communication platform featuring a persistent top-of-screen update ticker, searchable historical update repository, and process-specific admin push capabilities (9,000+ active users).
* **SQL Genie:** No-code/low-code visual SQL query builder enabling non-technical operators to drag-and-drop tables, fields, and filter conditions to generate, cleanse, and export custom data sets.
